# chc_analyses

Seasonal-forecast analyses built on the **Rosetta** (data access) and **DeepScale**
(forecast analysis) stack, reproducing operational CHC / FEWS&nbsp;NET forecast
products. Shared for co-development with the **CHC team** as expert end-user testers
of the stack.

## Analyses

| Directory | What it covers |
|---|---|
| [`chc_ethiopia/`](chc_ethiopia/) | Ethiopia **Kiremt** (JJAS) 2026 drought outlook and the East African **OND** short-rains ocean-state outlook, each reproducing a CHC deck. |

*New analyses are added as sub-directories, each with its own README; this table is the index.*
