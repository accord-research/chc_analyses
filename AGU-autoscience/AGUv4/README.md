# AGUv4 — discovered seasonal-forecast atlas

Can rainfall alone discover zones and seasons, with SST selecting each zone-season’s
recipe, and is the resulting atlas worth issuing out of sample?

| Read | What it is |

Headline: **USEFUL** — `atlas-wf-v2` / `zones-specific` / `rpss_atlas = 0.204416`, against a
200-replicate complete-season null (`f:19`). Caveats live in `a:1` (zonation gain) and
`a:2` (H1 untestable).

## Live pipeline (what you re-run)

```
data/                  locked fixtures (CHIRPS, ERSST)
bench.py, batched.py   inherited scorers (rx-locked)
harness/               atlas discovery → forecast → score (*_v2 is current)
candidates/            climatology arm
probes/                gates, null decisions, stability, scorer chain
run_atlas.py           real atlas + null + sensitivity
./run_v2_sequence.sh   Amendment-1 sequence (gates → benches → null → decide)
./regenerate.sh        full rebuild through rx (defaults to experiment e:3)
src/                   fixture fetch + env fingerprint
tests/                 wrap + scorer-agreement gates
outputs/               machine-readable results JSON / figures
```

`REPORT.md` is **not** generated by the scripts. Numbers come from `outputs/*.json`;
the prose is edited by hand.
